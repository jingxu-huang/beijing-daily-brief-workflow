# 测试版验收问题

## TEST-FEISHU-IMG-001：双图表格产生可见空表头

- 发现日期：2026-09-10
- 状态：待修复、不得进入正式版
- 影响范围：Markdown 双图排版与飞书 Docx 导入；不影响图片文件本身
- 现象：两张图片通过 Markdown 两列表格横排后，飞书将空表头渲染成一整行空白单元格，视觉上出现多余留白和表格边框。
- 根因：`资讯日报-skill/SKILL.md` 与 `format/格式规范.md` 指定使用 `| | |`、分隔行和图片行实现双图并排；`send_to_feishu_cli.py` 只本地化图片地址并原样保留表格；现有 `check_report.py` 未检查空表头或图片表格版式。
- 临时验收规则：测试版默认每条只保留一张代表图；确需两张时采用上下排列，不再生成图片表格。
- 后续候选方案：如必须横向并排，发布前将两张图合成为一张图片，或使用飞书专用布局 API；不得再依赖空表头 Markdown 表格。
- 修复验收：本地成稿、飞书暂存稿和飞书回读中均不存在图片表格或空表格；图片仍须完成数量与 SHA-256 一致性校验。
