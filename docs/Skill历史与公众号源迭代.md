## 对当前系统真正有用的结论

1. 当前正式日报依靠公开源，不依赖旧公众号三通道。测试版只在 weread-omni 当次 `healthy/cached` 且窗口文章/正文满足条件时才启用公众号增强；否则按真实状态降级。
2. 任何新源按“账号/订阅可见 → **本窗口文章列表新鲜** → 发布时间可信 → 正文完整 → 去重与日报采纳 → 连续运行”逐层验收。健康页、登录页、历史 Feed、缓存命中均不能跨级替代下一层证据。
3. 原始文章、游标、运行日志、历史日报和飞书索引登记保存在 Git 外；Git 只保留代码、配置模板、非敏感裁决及可复查的提交/产物位置。交接时这两类资产都要迁移，缺一不能宣称“完整恢复历史”。

若要继续补充新的来源迭代，至少记下：日期、方案与版本/提交、测试窗口和账号/源数、文章列表/全文/时间戳结果、错误原文的脱敏形式、是否进入日报、最后的采用/停用决定，以及证据所在提交或私有运行产物。无法核实的数字必须写“未验证”，不能补成推测值。
